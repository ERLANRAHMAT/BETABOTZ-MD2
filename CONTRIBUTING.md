# Contributing to WhatsApp Bot PPOB

Terima kasih telah tertarik untuk berkontribusi! 🎉

## Cara Berkontribusi

### 1. Fork Repository

Klik tombol "Fork" di pojok kanan atas halaman repository.

### 2. Clone Fork Anda

```bash
git clone https://github.com/your-username/whatsapp-bot-ppob.git
cd whatsapp-bot-ppob
```

### 3. Buat Branch Baru

```bash
git checkout -b feature/nama-fitur
```

Naming convention:
- `feature/` - untuk fitur baru
- `fix/` - untuk bug fix
- `docs/` - untuk dokumentasi
- `refactor/` - untuk refactoring

### 4. Buat Perubahan

- Tulis code yang clean dan readable
- Ikuti coding style yang ada
- Tambahkan comment jika perlu
- Test perubahan Anda

### 5. Commit Perubahan

```bash
git add .
git commit -m "feat: tambah fitur X"
```

Commit message format:
- `feat:` - fitur baru
- `fix:` - bug fix
- `docs:` - dokumentasi
- `style:` - formatting
- `refactor:` - refactoring
- `test:` - testing
- `chore:` - maintenance

### 6. Push ke Fork

```bash
git push origin feature/nama-fitur
```

### 7. Buat Pull Request

1. Buka repository Anda di GitHub
2. Klik "Pull Request"
3. Pilih branch Anda
4. Isi deskripsi perubahan
5. Submit PR

## Guidelines

### Code Style

- Gunakan 4 spaces untuk indentasi
- Gunakan camelCase untuk variable dan function
- Gunakan PascalCase untuk class
- Gunakan UPPER_CASE untuk constant
- Tambahkan semicolon di akhir statement

### Dokumentasi

- Update README.md jika menambah fitur
- Tambahkan comment untuk code yang kompleks
- Update CHANGELOG.md

### Testing

- Test semua perubahan sebelum commit
- Pastikan tidak ada error di console
- Test di berbagai environment (Termux, VPS, Panel)

### Commit Messages

Good:
```
feat: tambah command untuk cek saldo PPOB
fix: perbaiki error saat download TikTok
docs: update panduan instalasi Termux
```

Bad:
```
update
fix bug
changes
```

## Apa yang Bisa Dikontribusikan?

### Fitur Baru

- Integrasi API baru (PPOB, Payment Gateway, dll)
- Command baru
- Fitur AI/ML
- Database integration (MongoDB, MySQL, dll)
- Web dashboard

### Bug Fixes

- Fix error yang ada
- Improve error handling
- Fix memory leak
- Fix compatibility issues

### Dokumentasi

- Improve README
- Tambah tutorial
- Translate dokumentasi
- Tambah FAQ

### Optimasi

- Improve performance
- Reduce memory usage
- Code refactoring
- Better error handling

## Code Review

Semua PR akan di-review oleh maintainer. Kami akan:

- Cek code quality
- Test functionality
- Review dokumentasi
- Suggest improvements

## Pertanyaan?

Jika ada pertanyaan, silakan:

- Buat issue di GitHub
- Join grup Discord/Telegram (jika ada)
- Email maintainer

## Code of Conduct

- Be respectful
- Be professional
- Help others
- No spam
- No harassment

# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2024-11-02

### Added
- ✨ Fitur PPOB lengkap (Pulsa, Paket Data, PLN, E-Money)
- ✨ Downloader multi-platform (TikTok, Instagram, YouTube, Facebook, Twitter)
- ✨ Store menu dengan manajemen produk
- ✨ Sticker maker dari gambar dan video
- ✨ Auto RVO (Read View Once) untuk screenshot foto 1x lihat
- ✨ Owner menu dengan broadcast dan manajemen
- ✨ Mode public/self yang bisa diubah
- ✨ Database JSON untuk produk dan transaksi
- ✨ Helper functions lengkap
- ✨ Support Termux dan Pterodactyl Panel
- 📚 Dokumentasi lengkap (README, FAQ, Tutorial)
- 📚 Panduan instalasi Termux dan Pterodactyl
- 📚 Panduan integrasi PPOB

### Changed
- 🔄 Update ke Baileys v6.6.0
- 🔄 Struktur folder lebih terorganisir
- 🔄 Command handler yang lebih modular

- 🐛 Fix memory leak
- 🐛 Fix QR code display
